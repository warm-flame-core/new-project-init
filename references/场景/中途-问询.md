## 信息分层原则（中途/存量场景统一）

**进度状态类信息 → 以用户口述为准**（项目进行到哪、哪个模块在途——R1）；**技术事实类信息 → 以代码实测为准**（版本/结构/能否编译/文档是否过时——如存量文档记录的技术版本与实际代码不符，一律以代码实测为准）。两类权威来源不混用：进度不靠 agent 推断，技术事实不靠用户记忆。

> **进入本场景前置**：先探索（git status/log + 已有规范）→ 走 SKILL.md「执行流程·第 0 轮」能力摸底 → 再进入下方第 1 轮。每轮末尾备注填空规则同全新场景（必答但低打扰，实质内容记入 project-context 或相应模板章节）。
