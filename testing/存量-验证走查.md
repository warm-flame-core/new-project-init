> 走查方式：模拟一次「已有文档体系但不规范」的存量完善调用，重点验证「工作流闭环核查 + 文档冲突消解与联动核查流程」阶段 0 + A/B/C 四阶段。

## 前置

- [ ] 读取 `SKILL.md` 全文（含本次迭代改动点）
- [ ] **读取 `references/场景/存量-问询.md` 全文**（v11.0 强门禁：存量完善的限制规则 R1-R6、4 轮题库、阶段 0 + 冲突消解 A/B/C 完整版都在该文件；未读全文直接走查=违规）
- [ ] 确认改动点落点：存量完善问询（4 轮）、限制规则 R1-R6、工作流闭环核查（阶段 0）、冲突消解与联动核查流程（A/B/C）

## 走查步骤

0. **工作流闭环核查 · 阶段 0（v10.0 新增）**
   - [ ] 诊断工作流是否闭环：agents 角色/签署矩阵落地、记忆纪律（logs 跨天拆分/动作标签引用/入场核对）、会话管理（交接文档时机/上下文提醒）
   - [ ] 产出工作流缺口清单（同文档差距清单一起），随 R5 逐项确认
   - [ ] 文档还行但工作流不闭环 → 一并补（补规范文件缺 / 补模板产出物对应节），不顺手改业务代码（R6）

1. **限制规则验证（R1-R6）**
   - [ ] R1 进度必须用户口述（乱也全记；禁「让 AI 去看」）
   - [ ] R2 在途模块隔离（在途文档只记录现状）
   - [ ] R3 工作区谨慎（未提交改动先弄清来源）
   - [ ] R4 写操作确认（SQL 展示获确认 / commit 需允许）
   - [ ] R5 范围逐项确认（不默认全补）
   - [ ] R6 改造边界（对现有代码只记录不重构，结构性问题进演进清单）

2. **差距诊断（第 2 轮）验证**
   - [ ] 对着目标规范清单逐项勾（有/没有/不规范）
   - [ ] 「有」但「不规范」→ 先问用户要不要重写，不默认动

3. **冲突消解流程 · 阶段 A（每份被改造文档）**
   - [ ] 差异诊断：逐节对照模板产出差异清单
   - [ ] 冲突分类裁决：模板 vs 实际→实际；新旧冲突→口述/实测为准
   - [ ] 每处冲突选定动作（保留/按模板改/删除/待定），逐项用户确认

4. **冲突消解流程 · 阶段 B（跨文档去重）**
   - [ ] 重复扫描：同一信息多处出现（如验收门槛）
   - [ ] 唯一出处裁定：指定唯一出处，其余改引用不复制
   - [ ] 引用格式：`见 <AI协作规范文件>「记忆库纪律」` / `见 docs/已知坑/README.md` 式（v11.4 起；旧写法「见 CLAUDE.md C 区」应已绝迹）

5. **冲突消解流程 · 阶段 C（索引核查）**
   - [ ] 三层索引核对：file-index ↔ 实际文件；`<入口规范文件>` 文档索引 ↔ docs/；DOCUMENT-INDEX ↔ 全部
   - [ ] 链接检查：断链（含死引用：引用不存在的文件）→ 修复或删除
   - [ ] 每份改动文档变更记录追加一行（行内标注性质）
   - [ ] 入场核对联动：新会话发现不一致 → 按流程处理不自行裁决

6. **产出物新建门禁核对（v10.11，全量体检 ISSUE-002）**
   - [ ] 补建的每份文档都对照「产出物新建门禁总览」的模板核对表逐节比对
   - [ ] 不存在「把模板挪到真实位置就没特化/核对」的产出物
   - [ ] 新建文档必填结构（头部声明/维护声明/变更记录）均保留，on/off 跳过的章节有显式说明

7. **平台入口映射 + 规范装配问询（v11.0）**
   - [ ] 存量既有入口文件不论原文件名，问询确认后保留为正文；只为缺失平台补薄入口，不覆盖既有文件
   - [ ] 规范装配问询（27-34）逐模块问，按内容量裁决独立文件 or 并入 32/33/入口文件；默认关的（29/30/31）用户答「要」才产出；**34 已知坑为默认必建（不进按量裁决）**
   - [ ] 独立产出登记 DOCUMENT-INDEX + 信息闭环图；文档维护规则第 9 条方向对 **27~34** 适用（尾插）；**已知例外**：`README.md` 与 `docs/CREATION-LOG.md` 按版本倒序（新行在顶），改这两处按实际惯例插

8. **防遗忘与已知坑落点核对（v11.4 新增）**
   - [ ] 入口规范文件常驻区含 **★ 动作 → 必须更新** 表（8 类动作齐全，**原样生成不省略**）与 **★ 规范索引** 路由表（**本项目实际存在的每个规范文件恰好一行**，含「什么时候必须读」）
   - [ ] 存量项目原有的踩坑落点（入口文件环境速查表 / 部署文档「已知坑」节 / tools README「使用注意」）**已收敛为引用** `docs/已知坑/README.md`，旧处**不留表体副本**
   - [ ] `docs/已知坑/` 三件齐备（`README.md` + `_模板.md` + 至少把搬入的旧坑建成 `NNNN-*.md`）；README 体量 **1–3 KB**、**无变更记录表**（豁免已在第 9 条登记）；索引表的 `#` 与单篇文件名一致、状态列与单篇头部字段一致
   - [ ] 入口文件体量 **≤ 10 KB**（**> 8 KB 预警**；超了先外移再压缩，不许删硬门禁措辞）
