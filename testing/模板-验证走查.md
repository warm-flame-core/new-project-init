# 验证走查：模板生成完整性（testing/）

> 用途：**skill 迭代验证**（模板改完跑一遍「生成示例」验证结构完整）。每次改动模板后按受影响模板走查。
> 走查方式：用该模板生成一份示例产出（结构脱敏），对照「第一部分章节递归」逐节核对完整性。

## 前置

- [ ] 确认本次迭代改动的模板清单
- [ ] 读取对应模板全文（第一部分结构一览 + 第二部分详细规格）

## 走查步骤

1. **结构完整性**
   - [ ] 生成的示例覆盖第一部分「结构一览」的全部章节
   - [ ] 无章节缺失/错位/重复
   - [ ] 维护声明在头部、变更记录在末尾

2. **详细规格落实**
   - [ ] 第二部分每个最小标题的「写什么/格式/示例」都被使用
   - [ ] 无占位符残留（待定/TODO/类似任务 N 等，specs 类模板重点查）
   - [ ] 示例为结构示范，无 PTB-IMP 特有内容照抄（脱敏）

3. **on/off 与条件句**
   - [ ] 适用条件不满足的章节能跳过
   - [ ] 条件句（如 B4 多分支时、U13 要 CI 时）标注清楚

3b. **产出物门禁核对（v10.11，全量体检 ISSUE-002）**
