# 验证走查：模板生成完整性（testing/）

> 用途：**skill 迭代验证**（模板改完跑一遍「生成示例」验证结构完整）。每次改动模板后按受影响模板走查。
> 走查方式：用该模板生成一份示例产出（结构脱敏），对照「第一部分章节递归」逐节核对完整性。

## 前置

- [ ] 确认本次迭代改动的模板清单
- [ ] 读取对应模板全文（第一部分结构一览 + 第二部分详细规格）

## 走查步骤

1. **结构完整性**
   - [ ] 生成的示例覆盖第一部分「结构一览」的全部章节
   - [ ] 无章节缺失/错位/重复
   - [ ] 维护声明在头部、变更记录在末尾
   - [ ] **代码围栏嵌套正确（v11.4 新增检查项，实测踩过坑）**：模板里 ```` ```markdown ```` 示例块**内部若还嵌了** ```` ```bash ```` / ```` ```powershell ```` 等三反引号围栏，**外层必须写成 4 反引号**（```` ````markdown ````）——否则 CommonMark 下内层 ```` ``` ```` 会**提前闭合外层**，GitHub 渲染整段错乱（v11.4 实测 5 个模板中招：01/34/08/12/15）。自查：`(Get-Content <文件> | Where-Object { $_ -match '^````' }).Count` 与 `'^```(?!`)'` 计数**各自为偶数**。

2. **详细规格落实**
