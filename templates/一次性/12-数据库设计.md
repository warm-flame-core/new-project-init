## 第二部分：详细规格 + 示例

### 一、概述
- 数据库类型/版本、库名、字符集（utf8mb4）、迁移脚本约定（`sql/schema.sql` 权威 + `sql/V<编号>__*.sql` 增量，U1/U4）。
### 二、表结构设计
- 每张表一个 `###`：建表 SQL（与迁移脚本一致）+ 字段说明表（`字段 | 类型 | 必填 | 说明`）+ 索引说明。
- **字段注释必写**（表/字段都写 COMMENT），避免后续开发靠猜。
- **敏感字段标注（F2=有时，与 10 §七 安全要求呼应）**：身份证/手机号/银行卡等敏感列在字段说明表**备注列标注**——`脱敏展示（如列表半脱敏）` / `加密存储（AES/BCrypt）` / `禁打日志`。例：`id_card | VARCHAR(18) | 是 | 身份证号（列表脱敏展示，禁打日志）`。
### 三、实体关系图
- 核心表 1:N / N:M 关系文字描述（如「user 1:N student；training_project N:M student 经 enrollment 表」）。
### 四、索引策略
- 唯一键（业务唯一约束，如同校学号唯一）、常用查询索引（外键/状态）、最左前缀注意点。
### 五、枚举值定义
- 状态/类型字段取值表（如 user.status: 0 停用/1 正常）；有字典表的引用字典（module 数据字典模式）。
### 六、数据量预估
- 主表行数量级、年增长估算、分页/查询影响。
### 七、备份策略
- 备份方式（mysqldump 等）、频率、保留周期（F3 合规时必写）。

### 示例（结构示范）
```markdown
# 高校企业对接管理平台 - 数据库设计文档

## 一、概述
MySQL 8 + utf8mb4；库名 uepip；权威定义 sql/schema.sql，增量迁移 sql/V2__*.sql …

## 二、表结构设计
### user（用户表）
```sql
CREATE TABLE user (
  id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
  username VARCHAR(50) NOT NULL COMMENT '用户名（学号等）',
  phone VARCHAR(11) COMMENT '手机号',
  password VARCHAR(100) NOT NULL COMMENT 'BCrypt 密码',
  role VARCHAR(20) NOT NULL COMMENT '角色，见 RoleEnum',
  status TINYINT NOT NULL DEFAULT 1 COMMENT '1 正常/0 停用'
) ENGINE=InnoDB COMMENT='用户表';
```
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | VARCHAR(50) | 是 | 登录名；同校唯一（uk_school_username） |

## 三、实体关系图
user(1) ── (N) student：学生资料表，school_id 归属学校。

## 四、索引策略
- uk_school_username (school_id, username)：同校学号唯一
- idx_username (username)：登录查询兜底（最左前缀）

## 五、枚举值定义
- user.status：1 正常 / 0 停用
- user.role：PLATFORM_ADMIN / SCHOOL_ADMIN / STUDENT / …

## 六、数据量预估
user 表万级；student 表十万级以内；常规查询加索引可满足。
```
