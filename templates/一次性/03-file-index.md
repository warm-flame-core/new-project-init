## 第一部分：章节结构一览

```
memory/file-index.md
├── # 项目文件索引
├── ## 使用说明          ← 粒度规则：每模块 1 行 + 每入口文件 1 行；格式；状态图例
├── ## 1. 项目规范文件   ← CLAUDE.md / agents / .gitignore
├── ## 2. 模板/资源文件  ← templates/ file-templates/
├── ## 3. 记忆库文件     ← 本文件 + project-context + activity-log + logs
├── ## 4. 模块产出文件   ← 每模块 1 行汇总（specs 五件套目录 + 一句话）
├── ## 5. ADR            ← docs/adr/
├── ## 6. 源代码文件     ← 新 Controller/Service/DDL/配置（常规 CRUD 不登记）
├── ## 7. 测试代码文件   ← 按模块聚合
├── ## 8. 数据库迁移文件 ← sql/V<编号>__*.sql
├── ## 9. 开发工具       ← tools/
└── ## 快速查找指南      ← 按需查找表 + 文件类型速查
```

## 第二部分：详细规格

- **粒度规则**（防失控）：每模块 1 行 + 每入口/非常规文件 1 行，**非逐文件登记**；常规 CRUD 文件按模块聚合一句话。
- **索引行格式**：`| 文件路径 | 模块 | 类型 | 内容摘要（≤30字） | 创建时间 | 最后更新 | 状态 |`
- **状态图例**：🟢 活跃 / 🟡 待更新 / 🔴 已废弃 / 🗑️ 已删除。
- **删除不删行**：文件删除时标记 🗑️，保留索引（可回溯）。
- **谁维护**：产出文件的 agent 负责追加/更新自己的产出。
- **模块汇总**：每个 `specs/module-XXX/` 只占 1 行（五件套 + 一句话模块说明）。
- **快速查找指南**：`我想找… → 看哪` 表 + 文件类型速查表（谁产出、在哪）。

### 示例（结构示范）
```markdown
# 项目文件索引

## 使用说明
粒度规则：**每模块 1 行 + 每入口文件 1 行，非逐文件登记**。

## 4. 模块产出文件
| 模块 | 5 件套产出（目录） | 一句话模块说明 | 状态 |
|------|--------------------|----------------|------|
| module-001 | specs/module-001-xxx/ | <一句话>（plan + acceptance 签署 ✅ + …） | 🟢 |

## 6. 源代码文件（只登记入口/非常规）
| 文件路径 | 模块 | 类型 | 内容摘要 | 创建时间 | 最后更新 | 状态 |
|----------|------|------|----------|----------|----------|------|
| backend/src/main/java/com/xxx/controller/XxxController.java | module-002 | 代码 | <一句话> | YYYY-MM-DD | YYYY-MM-DD | 🟢 |

## 快速查找指南
| 我想找… | 看哪个章节 |
|---------|-----------|
| 项目当前状态 | memory/project-context.md |
| 某个模块的开发计划 | 第 4 节 → specs/module-XXX/plan.md |
```
