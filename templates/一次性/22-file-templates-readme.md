## 第二部分：详细规格

- **命名规范**：`<业务>-import-template.xlsx`（kebab-case 英文）；目录名 `file-templates/`（避免与项目 templates/ 冲突）。
- **通用版式**：第 1 行说明（填写指引）、表头样式、填写区行数约定；**数字列（学号/手机号/身份证）设文本格式**——防止 Excel 存成数值型丢精度（U5，本项目踩过坑）。
- **模板明细**：每模板 `### <模板名>`：`字段 | 必填 | 示例` 表 + 校验规则（如身份证本地校验码）+ 关联模板文件路径。
- **导出列格式约定**：数据清单类 → Excel（EasyExcel）；统计报表 → Excel/PDF；文档证书 → PDF；文件名 `<业务>-export.xlsx`。
- **存放位置**：方案 A 动态生成（代码生成，加业务列零改动）/ 方案 B 预置文件（resources 打包进 jar）——按项目实际定。
- **需求来源**：每个模板追溯到需求文档/模块，防「不知道模板为什么长这样」。

### 示例（结构示范，字段内容按项目特化）
```markdown
# file-templates/ 业务模板目录说明

## 命名规范
kebab-case 英文：`student-import-template.xlsx`；目录名用 file-templates 避免与 templates/ 冲突。

## 通用版式约定
- 第 1 行说明行（填写指引）；深色表头；填写区从第 3 行起
- **数字列（学号/手机号/身份证）必须文本格式**（防数值型截断）

## 模板明细
### 学生导入模板（student-import-template.xlsx）
| 字段 | 必填 | 示例 | 校验 |
|------|------|------|------|
| 学号 | 是 | 2026001 | 同校唯一 |
| 姓名 | 是 | 张三 | |
| 手机号 | 是 | 13800000000 | 11 位 |
| 身份证号 | 是 | 110101… | 本地校验码 + 日期合法 |

## 导出列格式约定
- 学生列表导出：Excel 10 列；审计日志导出：Excel 8 列

## 存放位置
方案 A 动态生成（推荐）：ImportTemplateGenerator 按字段列表生成，加业务列零改动。

## 需求来源
- 学生导入：module-012（需求文档 §X）
```
