# README.md 章节模板（模板 08）
> 🗂️ **产出模式**：一次性文档（skill 特化即正式文件，后续修改=更新式：改内容+变更记录+署名）；模板目录：templates/一次性/（v10.0 目录规整）
> 📍 **变更记录方向**：新行追加底部（有人看；见 SKILL.md 文档维护规则第 9 条）

> ⚠️ **维护声明**：本文档修改后必须在末尾「变更记录」表追加一行——`YYYY-MM-DD HH:mm | 变更内容 | 署名`（署名按三元组 人-角色-实例，如 张三-Developer-lead；无法确认实例先问用户）。
> **一次性文档**（E3=要时产出）。示例写在开头，agents 按问询答案在示例后**追加/替换填写**，产出即正式 README。
> 定位：项目门面——给人（同学/客户/答辩评委）看的第一份文档，要能在 1 分钟内看懂项目是什么、怎么跑起来。

---

## 第一部分：章节结构一览

```
README.md
├── # <项目名>
├── ## 项目简介        ← 一句话 + 给谁用 + 核心功能列表
├── ## 技术栈          ← 一行式选型（框架/库/数据库）
├── ## 快速开始        ← 前置要求 + 安装依赖 + 启动命令 + 访问地址
├── ## 目录结构        ← 顶层目录一句话说明
└── ## 默认账号        ← 演示账号（密码只写规则/占位）
```

## 第二部分：详细规格 + 示例

### 项目简介
- 一句话描述 + 给谁用 + 3-5 条核心功能（对应用户能感知的功能，不是技术点）。
- **示例**：
```markdown
# 高校企业对接管理平台

学校、培训机构、企业、学生之间的委托培训、实习、就业对接平台；含资质审核、合同管理、学生管理、实习就业、审计日志等模块。
```

### 技术栈
- 一行式列出前后端选型（版本可省，详版在 CLAUDE.md）。
- **示例**：
```markdown
## 技术栈
- 后端：Spring Boot 3 + MyBatis-Plus + MySQL + Redis + JWT
- 前端：Vue 3 + TypeScript + Element Plus + Vite
```

### 快速开始
- 前置要求（JDK/Node 版本）→ 安装依赖 → 启动命令 → 访问地址。**命令必须实测**（与 CLAUDE.md 常用命令一致）。
- **示例**：
```markdown
## 快速开始
前置：JDK 17、Node 18+、MySQL、Redis
```bash
cd backend && mvn spring-boot:run   # 后端，http://localhost:8080
cd frontend && npm install && npm run dev   # 前端，http://localhost:3000
```
数据库初始化：按顺序执行 sql/schema.sql → sql/V2__*.sql …（见 CLAUDE.md 常用命令）
```

### 目录结构
- 顶层目录一句话说明（backend/frontend/docs/sql/specs）。
- **示例**：
```markdown
## 目录结构
- backend/  后端工程（Spring Boot）
- frontend/ 前端工程（Vue 3）
- docs/     需求与设计文档
- sql/      数据库建表与迁移脚本
- specs/    模块开发规格（五件套）
```

### 默认账号
- 演示账号：账号可写，**密码只写规则或占位**（如 `admin / 见测试手册`），不写明文密码。
- **示例**：
```markdown
## 默认账号
平台管理员：platform_admin / 密码见 docs/测试手册「通用准备」章节
```
