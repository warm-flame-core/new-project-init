# memory/logs/<角色>/YYYY-MM-DD.md 章节模板（模板 05）
> 🗂️ **产出模式**：多次创建-单文件（无文件夹，复制特化模板文件新建）；模板目录：templates/多次-单文件/（v10.0 目录规整）
> 📍 **变更记录方向**：新行插顶部（纯 AI 看；见 SKILL.md 文档维护规则第 9 条）

> 模板用途：开发中**每角色每天新建一份**的「多次创建文件」。skill 结束时会在真实位置生成一份示例文件（如 `memory/logs/planner/YYYY-MM-DD.md`），后续 agent 新建当天日志时**复制示例文件**并按下方详细规格填写。
> 引用规则：第一部分=章节结构一览；第二部分=每个最小标题「写什么/格式/示例」，示例取自 PTB-IMP 项目实际日志（脱敏保留结构）。

---

## 第一部分：简化章节递归（结构一览）

```
memory/logs/<角色>/YYYY-MM-DD.md
├── # <角色>日志 — <YYYY-MM-DD>
│   └── > Agent: <角色> | 日期: <YYYY-MM-DD>（可加 | 模块 / | 工作目录）
├── ## 活动记录        ← 必填核心表：本日每个动作一行
├── ## 异常事件        ← 有异常才填：现象/根因/解决
├── ## 交接记录        ← 有交接才填：交出方→接收方/内容/文件
└── ## 今日统计        ← 收尾填：动作数/成败/耗时/主要产出
（可选补充节：## 本日工作 / ## 关键技术决策 / ## 待办移交 —— 叙述式详情，参考本项目 planner 日志）
```

## 第二部分：详细规格

### 文件命名与位置
- 路径：`memory/logs/<角色>/YYYY-MM-DD.md`；角色目录不存在先建（developer/planner/reviewer/tester + 新角色按需）。
- 一个角色一天一个文件；**动作即写**（每完成一个动作立刻追加），不攒到收尾。

> 🚨 **跨天拆分强制规则（v10.0，PTB-IMP 8-15 实测教训）**：
> - **新日期必须新建文件** `memory/logs/<角色>/<当天日期>.md`，**禁止在旧日期文件追加**新一天的内容（日期以系统时间为准，不凭记忆/惯性沿用）。
> - 跨天会话：先**封存**旧日期文件（补「今日统计」收尾），再**新建**新日期文件。
> - 写错日期/内容：用 `[CORRECT]` 追加更正行（`> 📌 <日期> [CORRECT]：...`），**不删改原记录**；确需迁移内容（如误写进旧文件）→ 复制到正确日期文件 + 旧文件留 [CORRECT] 说明。
> - 触发场景自查：写完日志前看一眼系统日期（`Get-Date` / `date`），与文件名核对一致再收尾。

### 头部
- 标题：`# <角色>日志 — <日期>`，如 `# Planner 日志 — 2026-08-08`。
- 引用行：`> Agent: <角色> | 日期: <日期>`；可追加 `| 模块: <module-XXX>`、`| 工作目录: <分支/工作区>` 帮助回溯上下文。

### 活动记录表（必填）
```
| 时间 | 模块 | 动作 | 产出文件 | 状态 | 耗时 | 备注 |
```
字段要求：
- 时间：`HH:mm`（或具体时刻）
- 模块：`module-XXX`；全局事项（如记忆库维护、入场自检）填 `-`
- 动作：动作标签 + 一句话动作。**标签表（20 个 + 语义）唯一出处见 CLAUDE.md C 区「记忆库纪律」**（PLAN/CLARIFY/CODE/FIX/BUILD/REVIEW/ADR/TEST/REGRESSION/SMOKE/BLOCKED/UNBLOCKED/HANDOFF/CONTEXT/CORRECT/ESCALATE/GIT/DB/CLEANUP/DOCS），本文件不重复定义。
- 产出文件：路径，多个用顿号分隔；无产出写 `-`
- 状态：`✅ 成功 / ❌ 失败 / 📋 待办`
- 备注：关键数字（如「mvn test 487/487」）、结论、待补测项
- 新记录**追加在表格底部**（时间正序），不插入中间。

### 异常事件表（有异常才填）
```
| 时间 | 模块 | 事件 | 描述 | 解决方式 |
```
- 事件：一句话（如「共享库结构漂移」）
- 描述：现象 + 影响面
- 解决方式：根因 + 修复/规避（写幂等迁移脚本 / 改代码 / 记录待处理）
- 无异常保留占位行 `| — | — | 今日无异常 | — | — |`。

### 交接记录表（有交接才填）
```
| 时间 | 交出方 | 接收方 | 模块 | 交接内容 | 交接文件 |
```
- 触发：跨会话 / 跨阶段交接（如 Developer→Reviewer、会话结束→新会话）
- 交接内容：本会话做了什么 + 对方接下来要做什么
- 交接文件：交接文档路径（如 `memory/handoff/<模块>-交接文档.md`，如已删则注明）

### 今日统计表（收尾填）
```
| 统计项 | 值 |
| 总动作数 / 成功 / 失败 / 阻塞 / 总耗时 / 主要产出 |
```
- 按活动记录表实计数；主要产出 = 当天关键文件路径。

### 可选叙述节（参考本项目 planner 日志写法）
- `## 本日工作`：按小节记录讨论/需求确认/读取实现（每行带来源）
- `## 真实代码盘点（禁止臆测）`：字段/逻辑盘点，标出来源文件
- `## 产出物`：`| 文件 | 说明 |` 表格
- `## 关键技术决策`：编号列出「决策标题：理由与落地」
- `## 待办 / 移交`：`待 Developer / 待 team-lead：…`
- `## 风险提示`：风险 → 已采取对策（与 plan §5 呼应）
